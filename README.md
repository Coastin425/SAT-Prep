# SAT Prep Pro 🎓

A comprehensive, interactive web application designed to help high school students study and prepare for the SAT. Track your progress, practice with realistic questions, create personalized study schedules, and learn proven test-taking strategies!

## 🚀 Features

### 📖 Study Materials
- **SAT-specific content** for Math, Reading, and Writing sections
- Checkable topic lists with real-time progress tracking
- Pro tips for each subject area
- 12 core topics aligned with actual SAT structure

### 🎯 Practice Questions
- Interactive quiz system with 15 practice questions
- Instant feedback with detailed explanations
- Progress tracking (questions answered, correct answers, accuracy rate)
- Questions cover all three SAT sections

### 📅 Study Schedule Planner
- Generate personalized study schedules based on your test date
- Customizable weekly study hours
- Detailed weekly breakdowns with specific daily tasks
- Scheduling tips and best practices

### 🧠 Test-Taking Strategies
- Before test day preparation checklist
- Time management strategies for each section
- Focus and concentration techniques (breathing exercises, physical resets)
- Secret test-taking hacks
- Motivational content to boost confidence

### 📊 Progress Tracking
- Visual progress bars for each subject
- Achievement system with 8 unlockable badges
- Overall statistics dashboard
- Persistent data storage using localStorage

## 🎨 Design Highlights

- **Modern, responsive design** that works on desktop and mobile
- **Engaging interface** with emojis, animations, and smooth transitions
- **Fun and interactive** with humor and interesting SAT facts
- **Clean navigation** with single-page application architecture

## 🛠️ Technical Details

- **Pure HTML, CSS, and JavaScript** - no dependencies required
- **localStorage** for data persistence across sessions
- **Responsive design** using CSS Grid and Flexbox
- **Zero external libraries** - lightweight and fast

## 📦 Getting Started

1. **Clone or download** this repository
2. **Open `index.html`** in any modern web browser
3. **Start studying!** No installation or setup required

```bash
# Clone the repository
git clone https://github.com/Coastin425/SAT-Prep.git

# Navigate to the directory
cd SAT-Prep

# Open in your browser
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

## 💡 How to Use

1. **Enter your name** on the home page to personalize your experience
2. **Navigate** using the top menu to access different sections
3. **Study Materials**: Check off topics as you complete them
4. **Practice**: Take quizzes to test your knowledge
5. **Schedule**: Create a personalized study plan based on your test date
6. **Test Tips**: Learn strategies to maximize your score
7. **Progress**: Track your improvement and unlock achievements

## 🎮 Achievement System

Unlock badges as you progress:
- 🎯 **First Steps** - Answer your first question
- 🔥 **On Fire** - Answer 10 questions
- 💯 **Century Club** - Answer 50 questions
- 🎓 **Sharp Shooter** - Achieve 80%+ accuracy
- 🌟 **Well Rounded** - Practice all subjects
- 📚 **Topic Master** - Complete 6+ study topics
- 📅 **Planner Pro** - Create a study schedule
- ⭐ **Perfect Round** - Get all 5 questions correct in a quiz

## 📚 SAT Content Coverage

### Math
- Heart of Algebra (linear equations, systems, inequalities)
- Problem Solving & Data Analysis (ratios, percentages, statistics)
- Passport to Advanced Math (quadratics, exponentials, polynomials)
- Additional Topics (geometry, trigonometry, complex numbers)

### Reading
- Main Ideas & Themes
- Command of Evidence
- Words in Context
- Analysis (author's craft, structure, purpose)

### Writing & Language
- Standard English Conventions (grammar, punctuation, usage)
- Expression of Ideas (organization, style, effectiveness)
- Sentence Structure (fragments, run-ons, modifiers)
- Punctuation (commas, semicolons, colons, dashes)

## ⏱️ Test Day Time Management

The app includes detailed timing strategies:
- **Reading**: 65 minutes, ~13 minutes per passage
- **Writing**: 35 minutes, ~8-9 minutes per passage
- **Math (No Calculator)**: 25 minutes, ~1.25 minutes per question
- **Math (With Calculator)**: 55 minutes, ~1.5 minutes per question

## 🔒 Privacy & Data

- All data is stored locally in your browser (localStorage)
- No data is sent to external servers
- Your progress stays on your device
- You can reset your progress at any time
